# Job Scheduler Automation System

A full-stack Job Scheduler application that allows users to create, view, run, and manage background jobs with priorities. The system includes a REST API backend and a modern dashboard frontend.

---

## 🚀 Live Demo

- **Frontend (Vercel):**  
  https://job-scheduler-automation.vercel.app

- **Backend API (Render):**  
  https://job-scheduler-automation-backend.onrender.com

---

## 🧠 Features

### Backend
- Create jobs with task name, priority, and payload
- Fetch all jobs
- Fetch job by ID
- Run a job manually
- Delete a job
- Reset all jobs
- Health check endpoint

### Frontend
- Create job form
- Job listing table
- View job details page
- Run job from dashboard
- Delete individual jobs
- Reset all jobs
- Connected to live backend API

---
